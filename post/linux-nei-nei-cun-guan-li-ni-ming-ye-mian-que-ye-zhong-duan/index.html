Linux内存管理-匿名页面缺页中断

2026-05-31 3 min read

通过这下面的实验代码，可以看出匿名页面缺页中断流程。

#include <stdio.h>
#include <stdlib.h>
#include <sys/mman.h>
#include <unistd.h>
#include <string.h>
int main() {
    size_t size = 12 * 1024; // 12KB
    pid_t pid = getpid();
    // 创建 12KB 的匿名私有映射
    char *ptr = mmap(NULL, size, PROT_READ | PROT_WRITE, MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
    if (ptr == MAP_FAILED) {
        perror("mmap failed");
        return 1;
    }
    printf("我的PID是: %d\n", pid);
    printf("mmap分配的虚拟地址是: %p\n", ptr);
    
    // 生成精确匹配这块内存地址的 grep 命令 (%lx 会输出类似 7f8b9a3d4000 的十六进制，正好匹配 smaps 第一列)
    printf("==================================================\n");
    printf("请在新终端复制并运行以下命令：\n");
    printf("cat /proc/%d/smaps | grep -A 15 '%lx'\n", pid, (unsigned long)ptr);
    printf("==================================================\n\n");
    printf("1. 目前刚 mmap 完，物理内存还没给。按回车开始写入前 8KB...\n");
    getchar();

    // 写入前 8KB
    memset(ptr, 'A', 8 * 1024);
    printf("2. 前 8KB 写入完成！此时你去终端跑一次上面的 cat 命令，你会发现 Rss 和 Private_Dirty 都是 8 kB。\n按回车继续读取最后 4KB...\n");
    getchar();

    // 读取最后 4KB
    char temp;
    for (int i = 8 * 1024; i < 12 * 1024; i++) {
        temp = ptr[i]; 
    }
    printf("3. 最后 4KB 读取完成。此时你再去终端跑一次 cat 命令，你会发现 Rss 依然是 8 kB！\n按回车退出...\n");
    getchar();

    munmap(ptr, size);
    return 0;
}

并发
当读多写少时候可以使用seqlock，它底层很简单就是有一个原子计数值，修改临界数据变成奇数 改完在变成偶数，然后读者在读的时候如果是奇数就在读几次。不用加锁，用于写少读多，但是只能保护一些简单的数据，如果保护一个指针，因为读者是无锁盲读的。如果写者正在释放一个指针并指向新地址，而读者刚好在盲读，就会瞬间引发野指针异常。还有一个rcu，通过复制来的，可对指针安全修改访问，同样也是适用读多写少。

在用户态，用 mlock() 锁定特定内存，或者用 mlockall() 锁定全家老小。

在内核驱动态，用 pin_user_pages() 强行把页面钉在内存里
