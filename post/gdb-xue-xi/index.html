显示源码调试 sudo gdb -tui ./uip，进入GDB后start，layout split能显示源码 汇编 命令窗口
frame # 显示当前函数、文件、行号

focus cmd # 焦点切到命令窗口，上下箭头翻历史命令
focus src # 焦点切到源码窗口，上下箭头滚动源码
focus asm # 焦点切到汇编窗口，上下箭头滚动汇编

p/d $esi # 看即将打印的整数

tbreak demo.c:8是一次性断点，打完即删除
until finish用来跳出循环和当前函数

return 可以在函数里面强行返回一个值

p a.src = 100可以设置一个变量

call func()直接能执行一个function
