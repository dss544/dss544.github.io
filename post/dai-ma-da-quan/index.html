###5
连续整数池中极速找回最小空闲编号 可以用位图，也可以用一个栈保存释放编号，如果栈控cnt才++。

###6
相同对象才能继承，比如苹果是水果。不相同只能包含，不如员工花名册包含一个链表（链表遍历名字），你不能这个类直接继承他。

让接口尽量可编程，比如你有一个函数是init，然后后面是对这个变量操作，有些人可能没有执行init直接操作可能报错，这时候你就把init返回一个对象指针。

里氏替换原则,子类继承父类父类函数,程序员上层调用父类对象执行这个父类函数不用管是那个子类,父类函数都是一样的含义.

如果共享数据而不是行为,那就不要继承,单独弄子类.比如一个步进电机驱动器和温控传感器都有

命名空间只是带一个标签的收纳箱,纯粹在编译期给一堆杂乱的全局函数和变量贴上分类标签,本身不会占用任何空间.

###7
在子程序中，不要把输入参数当作工作变量，不然调试不知道怎么修改值的。

###8
变量别一进函数就全部堆在最顶上声明，而要“随用随声明、就近初始化”，并且要在工程防御层面杜绝未初始化造成的内存幽灵 Bug。
尽量让变量能满足功能最小权限，比如能局部就不要全局。

###10
每个变量仅有一项用途
变量含义清晰没有隐含含义
所有声明变量均要使用且作用域要足够小
变量名中的计算值限定词一般放在变量最后，比如customercount
只有极短，不向外传递的循环变量，才会使用i，j。如果循环完还要使用这个变量，那就必须起有意义的名字。如果出现两层或多层循环嵌套，就不用i，j，k，容易写错应为i，j长得像。
下次定义临时变量不要一直用temp，说明根本没思考这个临时值的意义，尽量写真实名字。
可以去阅读下drivers/char/misc.c 与 drivers/char/random.c 内核的代码
使用bool变量不要在名字出现notfound这种带否定语义的，否则要产生双重否定。
枚举变量要加上组前缀，比如有两个一个enum Color 一个 enum TrafficLight，加上Color_Red，
TrafficLight_Red.

变量名和类型冲突，最好的方法就是把变量具体含义写上去，比如Button submitBtn。

内嵌空闲链表，可以固定链表内存，然后使用下一个。

typedef union Slot {
    // 槽位在使用中：存储真实业务数据
    struct {
        char name[32];
        float price;
    } data;
    // 槽位已释放：这块内存被复用为链表指针，指向下一个空闲槽位下标！
    int next_free;
} Slot;
static Slot g_pool[MAX_SLOTS];
static int  g_free_head = 0; // 空闲链表头节点
// 初始化：将所有槽位串成单向链表 (0 -> 1 -> 2 -> ... -> -1)
void pool_init() {
    for (int i = 0; i < MAX_SLOTS - 1; i++) {
        g_pool[i].next_free = i + 1;
    }
    g_pool[MAX_SLOTS - 1].next_free = -1;
}
// 分配：O(1) 立即弹出最前面的空闲槽位
int slot_alloc() {
    if (g_free_head == -1) return -1; // 满了
    int allocated = g_free_head;
    g_free_head = g_pool[allocated].next_free;
    return allocated;
}
// 释放：O(1) 将释放的槽位头插回空闲链表
void slot_free(int idx) {
    g_pool[idx].next_free = g_free_head;
    g_free_head = idx; // 下次分配优先复用这个刚释放的槽位！
}
