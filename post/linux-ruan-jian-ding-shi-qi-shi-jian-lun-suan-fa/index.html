linux软件定时器-时间轮算法

2026-06-06 8 min read

#一、 背景与痛点：为什么需要时间轮？
在操作系统中，管理定时器通常面临一个数据结构上的经典两难问题：
无序链表：插入极快 O(1)O(1)O(1)，但每次时钟中断检查谁到期了，需要遍历整条链表，时间复杂度 O(N)O(N)O(N)。在成千上万个定时器的场景下，CPU 会被活活累死。
按时间排序的链表（如 FreeRTOS）：检查到期极快 O(1)O(1)O(1)（只需看头部），但每次插入新定时器需要遍历寻找合适的位置 O(N)O(N)O(N)。
红黑树：红黑树插入和删除是O(logn)O(logn)O(logn)，到期检查取最小键值节点也是，综合性能远优于无序链表与有序单向链表；但仍存在短板：在百万级海量定时器的服务器场景下，单次插入
开销被海量调用持续放大。
为了在插入和检查触发上同时追求 O(1)O(1)O(1) 的极致性能，Linux 内核引入了极其优雅的数据结构——多级时间轮（Timer Wheel）算法。

#二、 核心思想：空间换时间与“多级齿轮”
Linux 的时间轮本质上是一个基于 32 位无符号整数（jiffies）的哈希表，通过位移（>>）和掩码（&）操作来代替耗时的除法和取余。内核将定时器分为 5 个级别（对应 32 位二进制的不同段位）：TV1（第 1 级）：256 个槽位（Slot），负责低 8 位（0~255 的滴答）。TV2 到 TV5（第 2~5 级）：各 64 个槽位，分别负责接下来的各个 6 位。
###1. O(1) 的插入（对号入座）
无论要延时多久，内核只通过两次极其快速的位运算：近期任务（<256<256<256）：expires & 255，直接挂入 TV1 的对应槽位链表。远期任务：通过 (expires >> 8) & 63，计算出高级表盘（如 TV2）的槽位并挂入。整个过程纯 O(1)O(1)O(1)，毫无遍历操作。
##2. 2. O(1) 的执行与降级级联（Cascade）日常触发
系统的“内部秒针”（timer_jiffies）每走一步，就直接拔出 TV1 当前槽位的整条链表，一口气执行完毕。级联进位：当 TV1 转满一圈（走完 256 步，低 8 位归零）时，触发 Cascade（级联）。内核会去 TV2 拉开对应的抽屉，把里面的远期定时器全部摘下来，重新计算它们剩余的时间，像天女散花一样把它们降级重新散落插入到 TV1 的 256 个槽位中。

#三、 核心源码解析（基于 Linux 4.1.15）
在 kernel/time/timer.c 中，整个算法由以下三个核心函数驱动：
##1. 插入引擎：
__internal_add_timer()所有 add_timer 或 mod_timer 最终都会调用此函数。它内部通过大量的 if...else if 和位移操作（>>），瞬间计算出定时器应该归属 TV1 还是 TVx，并使用标准的 list_add_tail 将其挂入双向链表。

static void __internal_add_timer(struct tvec_base *base, struct timer_list *timer)
{
    unsigned long expires = timer->expires;
    // 1. 算出相对当前内部秒针的差值（还有多久到期）
    unsigned long idx = expires - base->timer_jiffies;
    struct list_head *vec;

    // 2. 根据差值范围，决定放入哪一级的表盘
    if (idx < TVR_SIZE) { // 近期任务 (差值 < 256)
        int i = expires & TVR_MASK; // 等价于 expires % 256
        vec = base->tv1.vec + i;    // 定位 TV1 槽位
    } else if (idx < 1 << (TVR_BITS + TVN_BITS)) { // 稍远任务
        int i = (expires >> TVR_BITS) & TVN_MASK;  // 抹掉低8位后，等价于 % 64
        vec = base->tv2.vec + i;                   // 定位 TV2 槽位
    } else if (idx < 1 << (TVR_BITS + 2 * TVN_BITS)) {
        int i = (expires >> (TVR_BITS + TVN_BITS)) & TVN_MASK;
        vec = base->tv3.vec + i;
    } else if (idx < 1 << (TVR_BITS + 3 * TVN_BITS)) {
        int i = (expires >> (TVR_BITS + 2 * TVN_BITS)) & TVN_MASK;
        vec = base->tv4.vec + i;
    } else if ((signed long) idx < 0) { // 边界保护：超时或已被处理
        vec = base->tv1.vec + (base->timer_jiffies & TVR_MASK);
    } else { // 极遥远的未来任务，放入最高级 TV5
        int i;
        if (idx > MAX_TVAL) {
            idx = MAX_TVAL;
            expires = idx + base->timer_jiffies;
        }
        i = (expires >> (TVR_BITS + 3 * TVN_BITS)) & TVN_MASK;
        vec = base->tv5.vec + i;
    }
    // 3. O(1) 尾插法挂入目标槽位的双向链表
    list_add_tail(&timer->entry, vec);
}

##2. 执行心脏：
__run_timers()在 TIMER_SOFTIRQ 软中断中被调用。它包含一个 while (time_after_eq(jiffies, base->timer_jiffies)) 的追赶循环。只要内部秒针落后于真实时间，就会不断推进。极致的无锁回调：在拔出当前槽位的链表后，内核会果断释放自旋锁（spin_unlock_irq），让用户的定时器回调函数自由执行，防止阻塞其他 CPU 核心操作时间轮，执行完毕后再把锁拿回来。

static inline void __run_timers(struct tvec_base *base)
{
    struct timer_list *timer;
    spin_lock_irq(&base->lock); // 上锁，保护时间轮不被并发修改
    if (catchup_timer_jiffies(base)) {
        spin_unlock_irq(&base->lock);
        return;
    }
    // 1. 追赶循环：如果内部秒针落后于真实时间 jiffies，就一步步往前走
    while (time_after_eq(jiffies, base->timer_jiffies)) {
        struct list_head work_list;
        struct list_head *head = &work_list;
        // 获取 TV1 当前的槽位号 (0~255)
        int index = base->timer_jiffies & TVR_MASK;

        // 2. 级联触发逻辑 (核心齿轮运转)
        // 如果 index == 0，说明 TV1 转满了一圈，利用 && 的短路特性依次尝试降级高级表盘
        if (!index &&
            (!cascade(base, &base->tv2, INDEX(0))) &&
                (!cascade(base, &base->tv3, INDEX(1))) &&
                    !cascade(base, &base->tv4, INDEX(2)))
            cascade(base, &base->tv5, INDEX(3));
            
        ++base->timer_jiffies; // 秒针向前走一格
        // 3. 把 TV1 当前槽位的链表“连根拔起”放到 work_list 中，并清空原槽位
        list_replace_init(base->tv1.vec + index, head);
        // 4. 挨个引爆定时器
        while (!list_empty(head)) {
            void (*fn)(unsigned long);
            unsigned long data;
            bool irqsafe;
            timer = list_first_entry(head, struct timer_list, entry);
            fn = timer->function;
            data = timer->data;
            irqsafe = tbase_get_irqsafe(timer->base);
            timer_stats_account_timer(timer);
            base->running_timer = timer;
            detach_expired_timer(timer, base); // 从链表中彻底脱离
            // 5. 危险动作警告：剥离锁执行！
            // 执行用户的回调函数时，必须放开自旋锁，防止阻塞其他 CPU 操作时间轮
            if (irqsafe) {
                spin_unlock(&base->lock);
                call_timer_fn(timer, fn, data); // 自由执行回调
                spin_lock(&base->lock);         // 拿回锁，处理下一个
            } else {
                spin_unlock_irq(&base->lock);
                call_timer_fn(timer, fn, data); 
                spin_lock_irq(&base->lock);
            }
        }
    }
    base->running_timer = NULL;
    spin_unlock_irq(&base->lock);
}

##3. 搬家公司：
cascade()当 __run_timers 发现当前秒针的低 8 位全是 0（index == 0）时调用。它负责把高级表盘（如 TV2）对应槽位里的链表连根拔起，并遍历其中的每一个旧定时器，重新调用 internal_add_timer() 将它们降级塞回低级表盘。由于 C 语言的短路求值特性，级联操作代码写得极其精炼。

static int cascade(struct tvec_base *base, struct tvec *tv, int index)
{
    /* 把高级表盘 tv 中 index 槽位的所有定时器，降级搬运到下一级 */
    struct timer_list *timer, *tmp;
    struct list_head tv_list;
    // 1. 将目标槽位里的所有定时器连根拔起，存入临时链表 tv_list
    list_replace_init(tv->vec + index, &tv_list);
    // 2. 遍历刚刚拔出来的所有旧定时器
    list_for_each_entry_safe(timer, tmp, &tv_list, entry) {
        BUG_ON(tbase_get_base(timer->base) != base);
        // 3. 核心：由于此时 base->timer_jiffies 已经变大，
        // 重新调用添加函数时，它们会被自动“降级”分配到更低级的表盘（如 TV1）
        __internal_add_timer(base, timer);
    }
    return index; // 返回槽位号，决定是否触发更上一级的联动
}
